# 🎮 Games

A collection of small browser games built with **HTML, CSS, JavaScript, and the HTML5 Canvas API**.

Play the games directly in your browser. No frameworks, package installation, or build process are required.

## 🕹️ Games

| Game | Description | Play |
|---|---|---|
| **Block Dash** | An endless runner where you jump over incoming obstacles and try to beat your score. | [Play Block Dash](games/block-dash/) |
| **Stick Clash** | A local 1v1 stickman fighting game. Move, jump, and punch to defeat the other player. | [Play Stick Clash](games/stick-clash/) |

## ✨ Features

- Two browser-based games in one repository
- Simple landing page to choose a game
- HTML5 Canvas rendering
- No external libraries or dependencies
- Easy to run locally and publish with GitHub Pages

## 🎯 Controls

### Block Dash

| Key | Action |
|---|---|
| `Space` | Jump |
| `Arrow Up` | Jump |
| `R` | Restart after Game Over |

### Stick Clash

| Player | Move left | Move right | Jump | Punch |
|---|---|---|---|---|
| Player 1 | `A` | `D` | `W` | `F` |
| Player 2 | `←` | `→` | `↑` | `/` |

Stick Clash is designed for two players sharing one keyboard.

## 🚀 Run Locally

### Option 1: Open in a browser

1. Download or clone this repository.
2. Open the project folder.
3. Open the root `index.html` file in your browser.
4. Choose a game from the home page.

You can also open either game's `index.html` directly.

### Option 2: Use VS Code Live Server

1. Open this repository in VS Code.
2. Install the **Live Server** extension.
3. Right-click the root `index.html`.
4. Select **Open with Live Server**.

## 🌐 Deploy with GitHub Pages

1. Create a new GitHub repository named **games**.
2. Upload or push all files from this project.
3. Open the repository's **Settings**.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder.
7. Click **Save** and wait for GitHub Pages to deploy.

Your site will be available at:

```text
https://YOUR-GITHUB-USERNAME.github.io/games/
```

Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username.
