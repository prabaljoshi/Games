# 🎮 Games

Welcome to **Games**!

A collection of fun and interactive browser-based games built using HTML, CSS, and JavaScript.

This project is part of my journey into programming and web development. I'm building different games to improve my coding skills, explore game development, and learn by creating things.

## 🕹️ My Games

### 1. 🟩 Block Dash

An endless runner game where you control a player and jump over incoming obstacles. Try to survive as long as possible and achieve a high score!

**Controls:**

- `Space` – Jump
- `Arrow Up` – Jump
- `R` – Restart after Game Over

### 2. 🥊 Stick Clash

A two-player stickman fighting game where you can challenge a friend using the same keyboard. Move, jump, and punch your opponent to win!

**Controls:**

| Action     | Player 1 | Player 2 |
| ---------- | -------- | -------- |
| Move Left  | A        | ←        |
| Move Right | D        | →        |
| Jump       | W        | ↑        |
| Punch      | F        | /        |

## 🚀 Getting Started

Want to play these games on your computer?

Follow these simple steps.

### 1. Clone the repository

```bash
git clone https://github.com/Prabal Joshi/games.git
```

### 2. Open the project folder

```bash
cd games
```

### 3. Run the games

Open `index.html` in your web browser.

You can also use the **Live Server** extension in Visual Studio Code.

No additional installations or dependencies are required.
